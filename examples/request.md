# 示例需求 任务列表分页查询

以下为演示场景设定，不代表已有代码事实。

项目成员需要分批查看当前租户的任务，避免一次加载全部数据。请设计只读查询接口：默认每页20条、最多100条，支持连续查询下一页，末页明确返回结束标识。任务必须按当前可信身份进行租户隔离，客户端不能覆盖租户身份。

认证失败、没有读取权限、非法分页参数、非法游标、数据库超时应返回可区分的错误。说明稳定排序、空列表、同时间记录、分页期间新增或删除数据的行为与一致性边界。不包含任务创建、修改、删除、任意页跳转或新前端开发。

既有认证链路和任务数据源仅作为设计假设，未提供实际仓库。新增类、接口和索引应标为拟新增；列出待核实接入点及假设变化的应对方式。作者及实际issue/PR暂未提供，输出Draft并注明正式提审前补齐。
